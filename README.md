# ✅ Todo App

A simple and interactive Todo App built using **HTML, CSS, and JavaScript**. The application allows users to add, manage, complete, and delete their daily tasks.

## 📌 Features

* ➕ Add new tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 🔄 Dynamically update the task list
* 🖥️ Responsive user interface
* 🎨 Clean and user-friendly design
* ⚡ Interactive task management

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and user interface
* **JavaScript** – Application logic and DOM manipulation

## 📂 Project Structure

```text
Todo-App/
│
├── index.html
├── style.css
└── script.js
```

## ⚙️ How It Works

The Todo App uses **JavaScript and DOM manipulation** to manage tasks dynamically.

### ➕ Add Task

The user enters a task in the input field and adds it to the task list.

### ✅ Complete Task

Users can mark a task as completed when the task is finished.

### 🗑️ Delete Task

Users can remove unwanted tasks from the task list.

### 🔄 Dynamic Updates

JavaScript automatically updates the task list whenever a task is added, completed, or deleted.

## 🚀 How to Run

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

4. Start adding and managing your tasks.
